---
name: Bot feature merging
description: How Rakib AI should incorporate patterns from external WhatsApp bot projects.
---

Use clean-room implementations of compatible command patterns and architecture rather than copying source from GPL-licensed bot repositories into this project.

**Why:** The referenced FEE-XMD and XLICON-MD repositories are GPL-3.0, while this project started with an MIT package declaration; verbatim source merging would create licensing obligations that were not requested.

**How to apply:** Preserve attribution and license boundaries when expanding the bot. Prefer maintained, explicit provider integrations for external media and AI features.
